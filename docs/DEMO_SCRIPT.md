# Demo script (under 3 minutes)

## 0:00–0:20 — Hook

“What if your NFT wasn't a skin or a pass, but the game itself? This is Chog Escape Protocol. Every Chog changes the powers you have and the maze you face.”

Show the hero and selected NFT art.

## 0:20–0:55 — Provenance

Show the token metadata badge and MonadVision link. Point out Aura Fire, Round Crying eyes, Trackset body, and Russian Hat on token ID 973. Explain that the server reads `ownerOf` and `tokenURI` from Chog Genesis on Monad. A holder connects a wallet and enters their token ID; non-holders can use the labeled preview.

## 0:55–1:40 — Play

Start the Fire Chog preview. Move on the board, collect a fragment, use Firestorm to clear traps and stun drones. Show the turn count and the three-fragment objective. Use retry if necessary; this daily route stays deterministic for that token.

## 1:40–2:15 — The NFT changes the game

Switch to token ID 533. Show its cyan laser eyes, LASER ability, and different maze. Explain that Body/Head traits also change hearts and charges. This proves the NFT is a mechanic, not decorative art.

## 2:15–2:45 — Retention and honesty

Explain the maze rotates each UTC day and personal best is saved locally. Distinguish preview from verified owner play. No score is onchain and no token transaction is required.

## 2:45–3:00 — Close

“The next NFT meta isn't just what you own. It's the world only your NFT can play.” Show the live URL and repository.

**Before recording:** Use the deployed production URL, verify both token lookups work, capture an actual successful run, and keep the video at or below 3 minutes. Do not claim preview mode verifies ownership.
